# 82 人监控与 Slack App 交付

用户授权：开放 PAS 主语料库；82 位 AC 成员进入名单；部署 AWS；准备可直接连接测试的 Slack App。保留现有脏工作区。

1. 名单：从 data/ac_members.csv 导入全部 82 人。真实 OpenAlex 检索并核对姓名、机构、论文；不将模糊同名结果自动启用。记录证据及待确认项。
2. 交互：原生 Block Kit 周报＋线程卡片、反馈、App Home、/papers add 身份选择。所有论文先入 PAS，再通知。
3. 接入：复用 AWS，HTTPS 签名验证＋Lambda/SQS；无需常驻 Socket Mode 机器。单工作区 App manifest 安装；凭据加密写入 SSM；一次性连接码绑定操作者并创建本人私信，预览通过后启用通知。用户明确限制当前只能私信本人，代码拒绝群组频道。
4. 验证：作者真实 API / dry-run；状态去重及投递失败回归；交互签名/重放/权限/Slack API 错误；AWS endpoint 与完整监控任务。真实 Slack 收件需工作区完成安装，独立列出验收边界。

设计：科研组扫读优先，标题、作者、期刊、日期、来源和可验证链接；不生成无根据的相关性、合作或图片。界面采用 Slack 原生组件，不引入 CSS。日检索入库与每周通知分开。
